# Frontend — Кинотека

React + Vite + Axios frontend для REST API из лабораторной работы №1.

## Запуск

1. Установить зависимости: `npm install`
2. Запустить backend FastAPI на `http://127.0.0.1:8000`
3. Запустить frontend: `npm run dev`

Открыть адрес, который покажет Vite (обычно `http://localhost:5173`).

## Возможности

- Просмотр списка фильмов (GET)
- Добавление фильма (POST)
- Редактирование фильма (PUT)
- Удаление фильма (DELETE)
- Поиск по названию
- Фильтрация по году и минимальному рейтингу

## Структура

- `src/api.js` — Axios-запросы к backend
- `src/App.jsx` — интерфейс и логика приложения
- `src/App.css` — оформление
- `src/main.jsx` — точка входа React
